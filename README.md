# ForensicShield AI

Project 218 - Anti-forensic Technique Detection via Natural Language Processing for Forensic Text/Log Analysis, Applied to Ransomware Incident Post-attack Investigation.

## Features
- Forensic log analysis using NLP and Random Forest
- Explainable AI using SHAP
- SHA-256 evidence integrity verification
- Investigation timeline
- Hash-linked audit trail
- PDF investigation reports

## Public Demonstration
The public application uses three approved synthetic log records. Original research datasets are maintained separately.

## Research Evaluation
Primary NLP accuracy: 93.10 percent on 29 synthetic test records.
Independent external validation: NOT EVALUATED.

## Disclaimer
This academic tool supports investigator review. Candidate findings do not establish confirmed attacks or legal guilt.
