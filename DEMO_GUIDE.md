# Public Demonstration Guide

1. Start the application and sign in.
2. Create a new investigation case.
3. Open Evidence Intake.
4. Select Public Forensic Log Analysis Demo (3 Events - JSON).
5. Import evidence and run the detection model.
6. Review SHAP explanations, generate the PDF report and verify the audit trail.

The public demo uses public_demo_logs.json containing three synthetic records. Original research datasets and evaluation results are maintained separately.
